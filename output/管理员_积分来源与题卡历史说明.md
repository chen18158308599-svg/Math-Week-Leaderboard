# 管理员查看积分与题卡历史

## 如何使用

1. 使用管理员账号进入 `/admin`。
2. 点击 **Players**，按昵称或学校邮箱搜索玩家。零分玩家也能查到。
3. 点击 **Points & answers**，查看该玩家的积分来源及题卡提交历史。也可以在管理员积分榜或 Submissions 页面直接点击玩家昵称。

玩家详情包括：

- 当前排行榜总分。
- 每条得分的活动、领取方式、积分、时间和 Flag 标记。
- 每次题卡作答的题目、原始答案、正确／错误结果及时间。多空题逐项展示。
- 明细每页 50 条，可以翻页；时间统一为马来西亚时间。

## 历史数据说明

旧题卡记录仍保留正确／错误结果，但原始答案显示 **Not recorded**，无法恢复。

更新后，正式提交的原始答案与判题结果在同一数据库事务内保存。空白、格式错误、已完成或三次答错后被拒绝的提交不新增答题记录。原有判题、积分及三次错误锁定规则不变。

## 上线步骤

1. 在 Supabase SQL Editor 执行 `supabase/migrations/0027_card_answer_audit.sql`。
2. 部署本次网站代码。迁移不清空积分，也不更改旧答案结果；RLS 保持开启。
3. 用测试账号先答错再答对一题，确认管理员能看到两条记录、原始输入和对应积分。已完成的题目不能重复得分。

只有管理员可访问这些页面；普通玩家不能直接读取答题历史表。实际 Supabase 迁移和上线后演练仍需完成。
