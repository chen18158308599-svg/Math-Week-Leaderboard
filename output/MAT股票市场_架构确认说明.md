# MAT 股票市场：架构确认说明

用途：供构思者确认整体方向，暂不涉及程序实现。规则以现有 PDF 为准；价格变化细节按最新要求暂留空。

## 1. 在主网站中的位置

- 股票市场是 Math Week 主网站内的独立活动板块，与数字游戏、摊位活动并列。
- 建议复用主网站的学校账号登录与昵称，同一学生不必另注册账号。
- **共用身份，分开计分**：主网站原有活动积分榜保持原规则；股票市场另设虚拟资产排行榜。目前不将摊位积分兑换为交易资金，也不将投资结果加回活动积分。

网站关系：**主网站 → 股票市场 → 市场总览／个人资产／交易记录／市场排行榜**。

## 2. 游戏怎么玩

1. 玩家登录后获得 **M$5,000 虚拟现金**，初始没有持仓。
2. 查看各指数已公开的数据、价格走势及提示，推测后续变化。
3. 每天对每个指数最多确认一次操作：**买入、卖出或持有**；确认后当天不能再次操作该指数。
4. 每日截止后停止交易，公布下一期数据与价格，更新资产及排名。
5. 共八期观察数据、七次价格变化；最后一次变化后结算并冻结排名。

基本限制：每个指数初始价格 M$100；只交易整数单位；不允许透支、做空或玩家间转账；简化版不收手续费。玩家交易不会影响价格。

**排名依据：总资产＝剩余现金＋持仓按最新价格计算的价值。** 金额保留两位小数，相同总资产并列。

## 3. 玩家界面

| 页面 | 主要内容 |
| --- | --- |
| 市场总览 | 当前游戏日、开市／休市状态、交易截止时间、现金与总资产、各指数入口 |
| 指数详情 | 指数介绍、已公开走势与数据、提示区域、买入／卖出／持有操作 |
| 操作确认 | 操作类型、数量、成交价、总金额、操作后现金与持仓；说明将占用当天操作机会 |
| 个人资产 | 现金、各指数持仓、总资产；个人 QR 可放在现有个人资料页 |
| 交易记录 | 每次已确认操作的时间、数量、价格及现金变化 |
| 市场排行榜 | 仅公开名次、昵称、总资产，不公开个人持仓、邮箱或学号 |

首次进入显示简短“市场指南”。界面以手机操作为主，清楚显示剩余操作机会与交易状态。
