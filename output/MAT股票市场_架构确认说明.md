# MAT 股票市场：架构确认说明

更新：2026-10-15。本文记录已确认的活动架构，暂不实施功能。

规则依据：最新用户决定优先，其次为 `mat_stock_market/instructions/main_instruction/`。使用 `mat_stock_market/data/` 的数据作为行情基础；现有八天行情尚需调整为七天版本。

## 1. 在主网站中的位置

- 股票市场是 Math Week 主网站内的独立活动，与数字游戏、摊位活动并列，从 `/stock-market` 进入。
- 复用主网站学校账号和昵称，不另注册账号。
- **共用身份、独立计分**：主网站同时展示活动积分榜和股票资产榜，不兑换或混加两者分数。

页面关系：**主网站 → 股票市场主界面 ⇄ 市场排行榜**。股票详情、持仓及交易记录在主界面展开，买卖使用弹窗，不另设多个页面。

## 2. 七天游戏与现场参与

- 开赛前设置初始状态：每人 **M$5,000 现金、零持仓**；三只股票均为 **M$100.00**。初始化不占一个游戏日。
- 正式游戏共 **七天**，每天交易、收市结算；现金和持仓连续保留，不每日重置或强制清仓。
- **手机**：学校账号登录、昵称设置、确认现场配对；随时查看已公布行情、提示、资产与排名。
- **现场设备**：玩家用已登录手机扫描设备生成的短时、一次性二维码并确认，再在设备上交易。交易会话完成或超时后清除身份，后续交易需重新配对。
- 不采用固定签到码解锁全天手机交易，买卖必须经现场设备完成。

## 3. 交易时段与每日循环

以马来西亚当地时间（Asia/Kuala_Lumpur，UTC+8）为准，交易覆盖图书馆全部开放时段：

| 日期类型 | 可交易时段 | 截止与结算 |
| --- | --- | --- |
| 工作日 | 09:00–22:00 | 22:00 停止接受交易，再结算 |
| 周末 | 09:00–17:00 | 17:00 停止接受交易，再结算 |

节假日或临时闭馆按管理员事先公布的安排执行。截止前已打开确认页不代表成交，必须在截止前由服务器接受。

**变价安排建议：当天开放期间固定成交价格，闭馆后公布当天行情并更新价格。** 这样不同课表的学生在可到场时段获得相同报价，不需要为追逐整点变价反复到场。此项是结合开放时间提出的方案，尚待确认。

每日循环：**09:00 前公布提示 → 开馆后现场交易 → 闭馆停止交易 → 公布当天行情结果 → 更新资产榜**。

若采用上述变价方案，旧 CSV 的小时编号只用于内部行情路径，不能直接当作真实钟点；闭馆后可展示当天路径，但不开放沿途价格交易。最终一天也在交易截止后公布结果，再复核并冻结最终榜。

## 4. 已确认交易与排名规则

- 每只股票每天最多确认 **一次买入或卖出**。不同股票可分别操作；不操作即持有，无需到场按 Hold。
- 整数单位，至少1单位；无手续费；禁止透支、做空及玩家间转账。
- 确认时按服务器有效报价成交；若报价变化，重新展示金额并请玩家确认。
- **总资产＝现金＋各股票持有数量×当前价格**，保留两位小数，按总资产降序排名，相同金额并列。
- 每日结算只更新估值与市场排名，不将总资产重复加入活动积分榜。主网站展示每日市场榜与原有活动积分榜，最终市场名次由第七天结算资产决定。

## 5. 三只股票与行情

| 股票 | 数据主题 | 采用参数 |
| --- | --- | --- |
| LIB | 图书馆四闸门人流合计 | 相邻值差÷当天均值×5%，每个内部价格变化步限制 ±6% |
| BOOK | 每日借书 issue 笔数，不计 renew | 相邻值差÷当天均值×3.5%，每步限制 ±5% |
| DONA | 每笔有效图书捐赠册数 | 先取 LN(1+册数)，相邻调整值差÷当天调整值均值×4.5%，每步限制 ±6% |

每步新价格＝前价×（1＋限制后的涨跌率），四舍五入至两位小数。LIB 保留设计者推荐参数；BOOK、DONA 保持原方案。不加入 SCM 或第五只股票。

这些是历史数据映射的游戏行情，玩家买卖不影响价格。DONA 不代表真实历史逐小时记录。缺失数据冻结受影响股票并报警，不能当成0；BOOK 的真实 issue=0 保留。保留 M$50–M$200 的异常输入安全区间。

注意：每步 ±5%／±6% 并不代表整天涨跌也受同一限制，连续多步会累积。

## 6. 界面与后台

| 界面位置 | 内容 |
| --- | --- |
| 主界面顶部 | 现金、总资产、游戏日、交易状态及截止／结算时间 |
| 三张股票卡 | 名称、报价、涨跌和简短提示；现场配对后提供买入／卖出，显示今日操作状态 |
| 股票卡展开区 | 已公布走势；“了解这只股票”提供数据定义、统计单位和价格机制 |
| 交易弹窗 | 数量、方向、有效价格、总金额、交易后现金与持仓、今日操作机会 |
| 主界面底部 | 私人持仓及市值；交易记录折叠，按需查看 |
| 排行榜切换 | 公开名次、昵称、总资产及最近结算日期；不公开持仓、邮箱及学号 |

首次进入显示简短指南。提示每天交易开放前统一发布，先用“提示内容待补充”占位。

后台导入并审核完整路径、锁定版本、控制交易时段、发布行情、记录异常及交易、完成每日和最终结算。未来路径仅保存在服务器及管理员侧；玩家端不取得完整 CSV，不显示原始日期、来源月份、未来均值、管理员备注或捐赠者身份。
