# Directory 页面照片拍摄与替换清单

用途：让玩家看懂现场有什么、怎么玩、去哪里。当前页面使用插画占位，后续按下面编号替换。

## 优先拍这些

每项先拍 **1张横向封面＋2张细节或操作照**。目前页面每项使用1张封面，点击后放大查看同一张图；额外照片留作后续图库素材。

| 编号 / 文件名 | 拍什么 | 推荐构图 | 页面用途 |
| --- | --- | --- | --- |
| `exhibition.jpg` | 展览或数学装置全景 | 拍出主体和周围环境；有人驻足观看更好 | 展览预览 |
| `cards.jpg` | 玩家阅读、思考题卡 | 题卡与手部同框，避开答案和领取码 | 题卡预览 |
| `digital.jpg` | 玩家操作现场触屏 | 人物侧面＋完整屏幕，避开领取二维码 | 触屏游戏预览 |
| `hands-on.jpg` | 汉诺塔、Kanoodle、八卦等实体道具 | 道具近景＋手部操作 | 实体挑战预览 |
| `committee.jpg` | 委员会引导玩家挑战或听玩家解释 | 委员与玩家互动，展示道具 | 委员会挑战预览 |
| `market.jpg` | 现场股票市场界面 | 屏幕清晰、少反光，不显示个人资料 | 股票市场预览 |
| `opinion.jpg` | 玩家在数学意见墙贴纸投票或写便利贴 | 手部操作与墙上有趣的问题同框，拍出参与感 | Mathematics Opinion Wall 预览 |

## 顺手补拍位置照片

顶部三张照片拼贴沿用 `exhibition`、`digital`、`committee` 的封面，分别呈现装置／展览、触屏操作、现场合作，无需另拍一套。七项体验全部展开，定时活动只在当天有安排时显示紧凑日程。

- Library 2F：触屏与委员会摊位全景，最好带附近标识。
- Library 1F：讲座和合作摊位区域，拍出容易识别的位置。
- Mini Cinema：入口与门牌。
- 展览入口或主要装置：让第一次来的玩家认得路。

位置照先留作素材；当前页面以文字指引为主，未加入楼层地图。

## 拍摄要求

- 横向拍摄，主体尽量居中；预览裁为4:3，详情裁为16:9，四周留空间。
- 原图建议至少1600像素宽；交付 JPG 或 WebP，网页用图尽量控制在500 KB以内。
- 不加大段文字、水印或边框，标题由网页显示。
- 避开答案、个人账号资料和领取积分二维码。人物照片先确认对方愿意被用于活动展示。
- 没有玩家时可拍委员试玩，或只拍手部与道具，避免空桌成为封面。

## 替换位置

1. 把最终照片放进 `public/directory/`，使用表中的英文文件名。
2. 在 `src/lib/directory-content.ts` 将对应 `image` 路径从 `.svg` 改为 `.jpg` 或 `.webp`。
3. 换成 JPG 或 WebP 后，“PHOTO COMING SOON” 标记会自动消失；支持一部分保留占位图、一部分使用照片。图片会自动以活动类别作为描述，如需更具体的描述可再调整。
4. 核对手机和现场大屏上的裁切，重新部署网站。

## 发布前待确认

- PDF 安排周六闭幕、活动日期到周日：确认周日哪些摊位和展览仍开放。
- 确认各委员会摊位的值守时段和最终位置；页面不承诺全天有人。
- 电影标为13:00–15:00，但片长126分钟；需确认是否调整放映或闭幕时间。
- 当前定时活动采用流程 PDF 的安排；如主办方更新，以最终通知同步页面。
