# Digital游戏：改动与上线说明

本轮按设计确认稿及后续演练反馈实施。未清空现有积分、账号或股票数据。

## 已采用的短局

| 游戏 | 当前流程 |
| --- | --- |
| Conway | 每局培养一次（双方各8秒摆放、10秒演化），随后乒乓球最多25秒；得分或超时即结束该局。先得2分提前结束，最多3局后按总比分判定；总分相同平局，平局不领取赢家积分 |
| Planarity | 双方100生命；每解开一道题自动造成25伤害，移除技能栏；通常解开4题击倒对手；仅赢家领取 |
| KNN | 两张地图，每张破解保险箱、拿钥匙后从顶部出口离开；第二张完成后胜利 |
| 航海 | 两片海域、六艘海盗、四个宝箱；击沉全部目标获胜 |
| Number Sequence | 第一场：主怪3生命、两只小怪各1生命，完成自动教学；最终战：首领2生命，两名护卫各1生命且不复活。通常需要9次正确攻击 |
| Symmetry | 90秒生存挑战；每题10秒，计入总时间；生命耗尽失败，到时存活胜利 |

## 提示与操作

- 开始页用 Goal / Controls / Finish 说明目标、操作和结束方式。
- Conway 开始前显示四条生命规则及自动计算的前后示意，说明8个邻居；球场不再显示中央发球按钮，任一玩家挥动球拍自动发球。移除球场技能区，培养结果自动提升当局球拍力量；首次教学不重复出现。倒计时从进入球场开始，即使未发球也会到时结束该局；未分出胜负的该局不加分。
- 其他必要操作用黄色粗边框、光晕、箭头及短句提示；操作对应的高亮区域后才继续，空白点击不会跳过。纯说明类提示使用“Next hint”按钮。所有游戏移除How to play／问号帮助按钮，保留首次自动教学及开始页说明。
- 首次移动提示期间暂停场景；按下摇杆／高亮移动操作区立即收起并继续，不必松手。同次操作的松手不会跳过下一条。Symmetry 不新增局内教学。
- 摇杆160px；主要操作按钮至少约112×90px；地图宽250–260px，以实际显示尺寸校验。
- KNN任务移到上方中央；再次点击已选点会清除选中圈和勾号，数量同步减少。
- KNN“Check the required colour and K”说明允许点击任意处继续；其余提示仍要求对应操作。
- KNN确认错误答案后，本次选择标红并显示叉号、棋盘短暂震动；约0.85秒后允许重选。反馈期间禁止重复提交，保持原有3次机会规则；测量或取消选择不扣机会。
- 数列采用24道去重题组成的整局题库，不再循环出题；答错后换题，换关也不会重复上一题。
- 数列第一条提示同时高亮数列与四个选项；仅第一阶段自动教学，第二阶段不再出现教学；首领保护标记显示SHIELDED。
- 数列第一条提示进入战斗立即显示；后续提示等待操作恢复、攻击／击倒动画及对白结束，避免先闪现再消失。选择敌人的提示在点击存活敌人后收起。
- 数列移除“Now choose from the remaining answers”，使用洞察后直接提示选择敌人。
- Planarity先提示移动节点直到没有交叉；按下节点后说明消失，让玩家自行解题。解题后立即自动射击，不再要求点击技能。
- Planarity命中时显示“−25”伤害、明亮冲击环、闪光与受击后坐；减少动态效果模式保留伤害文字，取消后坐动画。
- Conway保留细胞规则和发球提示，移除两条“点击Confirm”的提示，确认按钮本身保留。
- Conway规则后的标题停留2秒；每秒演化时格子轻微震动，静止图案也有反馈；减少动态效果模式改用光圈反馈。进入乒乓球的提示放在结算按钮下方，不再遮挡结算内容。
- 航海成功购弹时，弹药框震动并显示+5 AMMO，金币处显示−300与金币粒子。
- KNN和Mirror Rush开始按钮前移，删除重复说明；Mirror Rush题目窗口复用本局倒计时，另标出10秒答题时间。

## 积分

每个活动仍只能领取一次，数字游戏最多19分。主动退出不结算。

领取积分在原换算基础上提高20%，向上取整，仍封顶19分：5→6、10→12、15→18。0分不变；Symmetry失败仍封顶9分，胜利仍在10–19分。只影响之后的领取，不补算已领取的历史积分。

Symmetry正常失败：1–9分；胜利：10–19分。失败领取前会明确提示“一活动只可领取一次”，也可返回重新挑战。

原始成绩口径（领取时再应用上述20%提升）：表现比例＝答对题数÷3×70%＋能源数÷40×30%，最多100%。胜利分＝10＋向下取整（9×表现比例）；失败分＝1＋向下取整〔8×（生存时间÷90×60%＋表现比例×40%）〕，最多9分。

其余游戏保留原有成绩构成，重新校准换算目标：Conway 1060、航海1623、KNN 4250、数列6850、Planarity 1350。Symmetry直接使用本局1–19分作为结果。

参考值说明：Planarity为解题攻击后满生命击倒；航海为六艘海盗、四个宝箱最高奖励、购买三次炮弹且满生命结束。旧积分不会被重新计算。

二维码仍有效60秒；重试不延长时间；重复扫码不重复加分。

双人游戏的领取卡片和二维码放在胜者所在半屏：P1左侧、P2右侧；仅赢家可领取。单人游戏保持居中，小屏幕保持完整可读的单列布局。

领取界面只保留领取积分、扫码说明、剩余时间、重试及返回主页；移除原始游戏分数和重复说明。返回主页使用整行按钮，二维码随可用高度缩放；在1280×720、1440×900、1920×1080验证无需滚动。

## 上线需要执行一次SQL

1. 在 Supabase 项目打开 **SQL Editor → New query**。
2. 未执行过0021时，先运行 `supabase/migrations/0021_digital_short_games.sql`；已执行则跳过。
3. 再运行 `supabase/migrations/0022_digital_medium_rounds.sql`，同步本轮积分参考值。
4. 运行 `supabase/migrations/0023_knn_two_maps.sql`，同步KNN两张地图的积分参考值。已执行过0021、0022时，只需执行0023。
5. 运行 `supabase/migrations/0024_digital_claim_points_boost.sql`，启用20%积分提升。已执行过0021–0023时，仅需执行0024。
6. 正常提交代码并部署网站，刷新现场浏览器。

该迁移更新短局换算及Symmetry失败领取资格，保留RLS和既有数据。无需重新运行旧迁移，也不需要重置数据库。

本地浏览器预览：`http://localhost:3000/games`。实际大屏的反光、观看距离和手指操作，仍需要现场复测。

## 已完成的验证

- 生产构建、TypeScript、lint、积分换算及本地数据库领取规则测试。
- 浏览器实际完成 Conway 培养、挥拍发球和得分后重返培养，数列9道不同题目通关、Planarity解题自动攻击至击倒，并检查赢家二维码。
- 浏览器实际触发 Symmetry正常失败，检查失败结果进入1–9分二维码流程。
- 检查摇杆和地图实际尺寸、规则示意、提示定位与操作按钮可点击。
- 在1280×720和1440×900检查KNN、Mirror Rush开始按钮无遮挡；验证购弹数值与反馈、Planarity逐条提示、数列第一阶段教学及第二阶段不自动教学、Mirror Rush两处本局计时一致。
- 检查按需加载、结束后释放游戏、二维码重试不续期。

浏览器二维码接口使用模拟响应，数据库规则使用本地测试库，未向正式排行榜写入测试积分。正式Supabase仍需执行上面的新迁移。
