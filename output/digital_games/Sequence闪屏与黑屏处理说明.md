# Sequence 闪屏与黑屏：第二轮处理

这轮没有在实际 MAXHUB 上复现或确认根因。以下修改针对源码中发现的遮罩、首次缩放和图形合成风险，并已通过本地回归。

- 所有游戏 hint 移除全屏 SVG 镂空暗色遮罩，保留黄色重点框和文字；边框不再闪动。减少提示位置的小数抖动及重复暂停事件，限制文字框位置，避免跑到视口上方。
- Sequence 把居中位移和缩放统一到传统 `transform`，不再依赖单独的 CSS `translate` 来居中，降低旧浏览器只显示局部画面的风险。
- Sequence 在首次绘制前计算尺寸，并监测容器、窗口与可视视口变化，避免全屏切换或 iframe 尺寸变化后仍使用旧缩放值。
- 进一步关闭 Sequence 大面积背景、入口传送动画、全屏红色闪光、Boss 闪光及场景震动。保留题目、按钮、敌人、命中提示和计分。保留原有按高亮操作推进 hint 的机制。

验证：lint、生产构建、游戏计分测试通过；完整六款游戏短流程回归通过，包括 Sequence 九题通关、提示推进和结果领取。新增 `scripts/verify-sequence-rendering.mjs`，检查 1280×720、1920×1080、3840×2160 视口变化后开始页和游戏画面居中且完整可见，答案按钮未被裁切；黄色重点框保留，无全屏 SVG 遮罩或页面运行异常。数字游戏性能与失败恢复测试也通过。未创建真实积分。

重新部署后请在 MAXHUB 强制刷新再测试。如果仍出现半屏黑屏，下一步需要对比独立游戏入口与嵌入页面，并收集最早的 Console 错误、浏览器版本及 GPU 状态，不能仅凭现象断定是 hint 导致。无需 SQL 操作。
